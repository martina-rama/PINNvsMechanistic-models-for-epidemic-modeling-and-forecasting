# data/

Input data only. Nothing here is a result of the comparison.

## synthetic/

Generated by `notebooks/01_synthetic_data.ipynb` (`pinnvsmech.data.synthetic`), seed 42.

- `deterministic_syntheticdata_normalized_2R0s_Tweekly.csv` – ODE trajectories of all compartments, no header. Columns: `[t, R0, delta_param | S, E, I, R, D, Dobs (16 age classes each, fractions of N_age) | scenario index]`.
- `SEIRDDobs_syntheticdata_parameterspairs_2R0s_Tweekly.pickle` – the (R0, delta) pairs, one per scenario.
- `synthetic_R0_<R0>_noise_<light|mild>.pkl` – one file per scenario and noise level, a dict with:
  - `t`: days
  - `noisy incidence`: weekly incidence with Negative Binomial noise (r = 100 for `light`, r = 50 for `mild`)
  - `incidence`: weekly incidence without noise, aggregated
  - `age incidence`: weekly incidence without noise, per age class

## training/

Data used to train the PINN, generated by `notebooks/02_pinn_training.ipynb` (`pinnvsmech.data.pinn_training_data`). Parameter space: R0 in [1.3, 3.0], Delta (mean delay, days) in [7, 35]. Initial condition: one infected per age class.

- `deterministic_dataset_33_PINN.csv` – training set: 33 x 33 grid of (R0, Delta), weekly grid over [0, 365] (53 points), 57717 rows, no header. Columns: `[t, R0, Delta | S, E, I, R, D, Dobs (16 age classes each) | scenario index]`. **118 MB: above the GitHub limit of 100 MB, so it is not stored in the repository.** It is deterministic: `notebooks/02_pinn_training.ipynb` regenerates it automatically when the file is missing (about 1 minute; requires the contact matrix in `data/epi/`).
- `SEIRDDobs_training_parameter_pairs_33.pickle` – the (R0, Delta) pairs of the training grid.
- `SEIRDDobs_collocation_parameter_pairs_32.pickle` – collocation points `[t, R0, Delta]`, array of shape (374784, 3): 32 x 32 midpoints of the parameter grid, daily grid over [0, 365].

## epi/

Real epidemiological data and contact matrices.

- `contact_matrices_152_countries/` – the files `MUestimates_all_locations_1.xlsx` and `MUestimates_all_locations_2.xlsx` (Prem et al.), read by `pinnvsmech.data.load_matrices`. Needed to generate the synthetic data and the training set of the PINN, and to train it.
- `london/deaths.csv` – weekly COVID-19 deaths in London, read by `pinnvsmech.inference.cases.load_covid_deaths`. CSV with the columns `date` (week, first column) and `deaths` (new deaths in the week); the first wave (2020-02-16 to 2020-08-02) is selected when it is loaded.

## mechanistic_raw/ (not tracked)

Optional input of `notebooks/05_mechanistic_results_format.ipynb`: the raw results of the Mechanistic model, produced by its own repository, one folder per case (`real_London/`, `synthetic_R0_<R0>_noise_<noise>/`) with one subfolder per look-back (`nall`, `n4`, `n5`, `n6`). Not stored here (large); the converted results are in `precomputed/posteriors/mechanistic/`.
